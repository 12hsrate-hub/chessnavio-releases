## Проверка скачанного файла

Сравните SHA-256 архива со значением в `SHA256SUMS.txt` из того же выпуска.
Если сумма не совпадает, не устанавливайте файл и сообщите в поддержку.

Стабильные GitHub Releases защищены режимом неизменяемости. После публикации
архивы и связанный с выпуском тег нельзя незаметно заменить. GitHub CLI также
позволяет проверить аттестацию релиза и соответствие локального файла.
